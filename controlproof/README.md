| `ARCHITECTURE.md` | Recommended stack, data flow, security boundaries |
| `DATA_MODEL.md` | Proposed schema and tenant-isolation design |
| `THREAT_MODEL.md` | Threats, mitigations, remaining risks |
| `IMPLEMENTATION_PLAN.md` | Go / no-go criteria, phases, who does what |
